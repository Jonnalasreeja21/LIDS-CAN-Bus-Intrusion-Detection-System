# LIDS: Lightweight Intrusion Detection System

## Overview

LIDS is a Flask-based CAN Bus Intrusion Detection System designed to monitor vehicle network traffic and identify malicious activities in real time.

The project simulates CAN traffic and visualizes anomaly detection results through an interactive dashboard.

---

## Features

✔ Real-time CAN Bus Monitoring

✔ Live Threat Detection

✔ SQLite Database Integration

✔ Attack Simulation Engine

✔ Historical Reports Dashboard

✔ Flask-Based Web Interface

## Installation

### Clone Repository

git clone https://github.com/Jonnalasreeja21/LIDS-CAN-Bus-Intrusion-Detection-System.git

### Install Dependencies

pip install -r requirements.txt

### Initialize Database

python init_db.py

### Run Simulator

python simulate.py

### Run Dashboard

python app.py

Open:

http://127.0.0.1:5000
